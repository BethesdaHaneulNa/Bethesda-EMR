2. 직원 눈에 보이는 변화를 먼저, 안 보이는 것(잠금·검사·마이그레이션)은 뒤에 짧게.

6. 길이는 모듈마다 화면 한두 쪽. 자세한 것은 위키 모듈 페이지 8절을 가리킵니다.
