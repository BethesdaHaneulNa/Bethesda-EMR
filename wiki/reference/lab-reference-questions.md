## 2. 판정 기준선 — 「이 값을 넘으면 빨강」

한국 검사실은 아래 항목을 참고범위가 아니라 학회 판정 기준으로 보고합니다. 빨간 표시를 어디서부터 붙일지 골라 주세요.

| 항목 (단위) | 지금 EMR | 빨강 기준 — ○ 표시 | 기타 |
|---|---|---|---|
| 공복혈당 (mg/dL) | 70–100 | ① 100 이상 빨강 (학회 「공복혈당장애」부터) ② 126 이상 빨강 (당뇨병 기준) ③ 110 초과 (서울대) | |
| HbA1c (%) | 4.0–5.6 | ① 5.7 이상 빨강 (당뇨병전단계부터) ② 6.5 이상 빨강 (당뇨병 기준) | |
| 총콜레스테롤 (mg/dL) | 0–200 | ① 200 이상 (경계부터) ② 240 이상 (높음부터) | |
| 중성지방 (mg/dL) | 0–150 | ① 150 이상 (경계부터) ② 200 이상 (높음부터) | |
| LDL (mg/dL) | 0–130 | ① 130 이상 (경계부터) ② 160 이상 (높음부터) ③ 100 이상 (적정 초과부터) | |
| HDL (mg/dL) | 40–60 | ① 40 미만만 빨강, 위로는 제한 없음 (학회·GC·이원) ② 남 35–55 · 여 45–65 (서울대) ③ 지금대로 | |
| eGFR (mL/min/1.73m²) | 90 이상 | ① 60 미만 빨강 (검사기관·검진) ② 90 미만 빨강 (지금대로) | |

## 3. 글자 결과 · 소아

| 질문 | ○ 표시 | 기타 |
|---|---|---|
| 요검사 **Trace(미량)** 는 이상(빨강)으로 볼까요? (지금: 이상) | ① 이상으로 ② 정상으로 (삼광·아산은 정상 범위에 포함) ③ 단백만 정상, 나머지는 이상 | |
| 요검사 「Absence」(프랑스어 음성 표기)는 음성과 같게 볼까요? | ① 예 ② 아니오 | |
| **소아 참고치**를 따로 넣을까요? (지금: 성인 값 하나로 판정) | ① 넣는다 — 기준: ⓐ 서울대 소아표 ⓑ 한국 소아 연구(Sung 2021) ⓒ 삼광 ② 지금은 넣지 않는다 | |
| 소아 참고치를 넣는다면, 먼저 넣을 항목 | ○ Hb·Hct ○ WBC ○ Platelet ○ ALP ○ Creatinine ○ 기타: ______ | |
| 생년월일을 모르는 환자에게 쓸 기본값 | ① 성인 공통값 ② 성인 남성값 ③ 기타 | |

## 참고

- 성별·나이별 참고치는 EMR에 넣을 준비가 되어 있습니다(설정 → 검사항목 → 성별·나이별). 나이는 검사한 날 기준이며, 생일 당일부터 새 구간이 적용됩니다.
- 찾은 자료는 모두 외산 장비 기준이었습니다. 현장 장비(한국산)로 건강한 사람 검체를 몇 건 확인해 보시는 것도 방법입니다(확인 필요).
