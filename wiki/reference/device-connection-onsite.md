# 현지에서 영상 장비 붙이기 — 순서서 (실장님용)

> 가져가는 장비: 후지 X-ray(옛 모델), GE 초음파(옛 모델), 위·대장내시경 게이트웨이 컴퓨터 — **모델은 아직 모릅니다.** 한국에서 미리 붙여 볼 수 없어서, 현지에서 서버 PC 앞에 앉아 장비 설정 화면을 보며 맞춰 갑니다.
> 이 순서서는 모델을 몰라도 쓸 수 있게 **일반적인 말**로 적었습니다. 장비마다 메뉴 이름이 다르니, 모르는 것은 **「확인 필요」**라고 적어 두었습니다 — 지어낸 것은 없습니다. 그날 알게 된 것은 맨 아래 빈칸에 채워 주세요.
> 쓴 사람: PACS 세션 (2026-09-30). 도구: PACS 폴더의 **`device-watch.bat`**.

## 한눈에

1. 서버 PC에서 **`device-watch.bat`**을 두 번 눌러 켜 둡니다 — 장비가 무엇을 하는지 한 줄씩 보여 줍니다.
2. 장비 설정에 **세 가지**를 넣습니다: 서버 주소(서버 PC의 IP), 포트 **4242**, 서버 이름(AE Title) **MEDCONNECT**.
3. EMR에서 시험용 환자에게 영상 검사를 하나 냅니다.
4. 장비에서 목록(워크리스트)을 불러와 그 환자가 보이는지 → 찍어서 보냄 → EMR에서 「Réalisé」와 영상 창.
5. 막히면 아래 「단계와 판정」 표에서 device-watch 화면의 글자를 찾습니다.

## 시작 전에

### 서버 PC

- **고정 IP**: 공유기(라우터)에서 서버 PC에 늘 같은 주소를 주게 합니다(「DHCP 예약」, 「고정 할당」 — 공유기 메뉴 이름은 제품마다 다름). 장비가 이 주소로 보내므로, 주소가 바뀌면 장비가 모두 끊깁니다.
- 서버 PC의 주소 알기: PACS 설치가 끝날 때 「Imaging devices send to this PC: 192.168.x.x」로 알려 줍니다. 또는 명령 창에서 `ipconfig` → 「IPv4 주소」.
- **Windows 방화벽**: 장비에서 4242로 못 들어오면 방화벽이 막는 것일 수 있습니다(아래 ①). 네트워크 종류를 「개인」으로.

### 장비에 넣을 값 셋 (모든 장비에 같음)

| 무엇 | 넣을 값 | 장비 화면에서 흔히 보이는 이름 (장비마다 다름) |
|---|---|---|
| 서버 주소 | 서버 PC의 IP (예: 192.168.1.10) | Host, IP Address, Server IP, Remote IP |
| 포트 | **4242** | Port, Remote Port |
| 서버 이름 | **MEDCONNECT** (대문자) | AE Title, Called AE, Remote AE, Destination AE |

- 이 셋을 **두 곳**에 넣어야 할 수 있습니다: **목록 받기**(Worklist, MWL, MWM, Modality Worklist) 와 **영상 보내기**(Store, Send, Storage, Archive, PACS). 장비에 따라 한 화면일 수도, 따로일 수도 있습니다.
- 장비 **자신의** 이름(AE Title)과 IP도 설정에 있습니다. 서버 쪽은 아무 이름이나 받으므로 바꿀 필요는 없지만, **적어 두세요**(device-watch 화면에 그 이름으로 나옵니다).
- 서버 이름을 조금 틀리게 넣어도(예: MEDCONECT) 지금 서버는 받아 줍니다. 그때 device-watch가 「장비가 서버 이름(AE)을 「…」로 부름 — 맞는 이름은 MEDCONNECT」라고 알려 주니 고쳐 두세요.

### device-watch 켜 두기

- PACS 폴더(보통 `C:\Bethesda-PACS`)의 **`device-watch.bat`** 두 번 누르기. 한국어로 나옵니다(프랑스어: 명령 창에서 `device-watch.bat -Lang fr`).
- 처음에 「※ 자세히 보기 …」가 나옵니다 — 장비의 연결·목록 조회까지 보려고 영상 서버의 기록을 잠시 자세히 하는 것입니다. **끝낼 때는 Ctrl+C** — 「자세히 보기를 끄고 … 되돌렸습니다」가 나온 뒤 「일괄 작업을 끝내시겠습니까 (Y/N)?」에 **Y**. 창의 X로 닫았으면 `device-watch.bat -Reset`을 한 번 실행합니다(안 해도 영상 서버를 다시 켜면 돌아가지만, 그 사이 기록이 많아집니다).
- 30초 동안 아무 일도 없으면 「기다리는 중 — 아직 아무 장비도 연결하지 않음」이 나옵니다.

### EMR에서 시험 검사 내기

- 시험용 환자(예: 「TEST Device」)를 접수 → 진료에서 그 장비의 검사를 하나 냅니다(X-ray면 Chest PA 같은 CR 검사, 초음파면 US 검사). 줄 오른쪽에 **Envoyé**.
- **오늘 낸 검사만** 장비 목록에 나옵니다.

## 장비에서 찾을 것 (모델을 몰라도)

- 설정 메뉴 이름 후보: **DICOM**, **Network**, **Connectivity**, **Service**, **System**, **Setup**, **Configuration**. 대개 **서비스용 비밀번호**가 필요한 칸에 있습니다 — 비밀번호는 장비와 함께 온 서류, 이전 병원의 기사, 제조사에 물어야 할 수 있습니다(확인 필요).
- 목록 받기: **Worklist / MWL / MWM / Modality Worklist / RIS**. 영상 보내기: **Store / Send / Storage / Archive / PACS / Destination**.
- **거르기**(필터): 「내 AE만」, 「Station AE」, 「This station only」, 「Modality」, 「Date: Today」 같은 칸. **내 AE만 / Station AE는 끄세요** — EMR 검사에는 장비 이름이 붙지 않아 켜 두면 늘 0명입니다(위키 P-8). Modality 거르기는 켜 두어도 되지만, 장비가 묻는 종류(CR, DX, US, ES …)와 EMR 검사의 종류가 같아야 합니다(아래 「EMR 쪽 설정」).
- 장비에 「연결 시험」(Echo, Verify, Test, Ping) 단추가 있으면 먼저 눌러 봅니다 — device-watch에 「장비가 연결 시험(C-ECHO)을 함 → 응답함」이 뜨면 선은 된 것입니다.

### 장비 종류별 메모 (모델을 알면 채울 곳)

| 장비 | 알고 있는 것 | 확인 필요 |
|---|---|---|
| 후지 X-ray (CR/DR 콘솔 PC) | 영상은 보통 **콘솔 PC**(장비 옆 컴퓨터)에서 보냅니다. 전송 목적지·워크리스트 설정은 콘솔 소프트웨어의 설정/서비스 쪽에 있는 경우가 많습니다. | 워크리스트 기능이 **따로 사는 옵션**인지(없으면 아래 「워크리스트가 안 되는 장비」). 서비스 메뉴 들어가는 법·비밀번호. 영상 종류가 CR인지 DX인지(EMR 오더 코드의 Modality와 맞출 것). |
| GE 초음파 | 많은 기종에서 **DICOM 자체가 옵션(키)**입니다 — 키가 없으면 목록 받기도 **전송도** 안 됩니다. 설정은 흔히 **Utility → Connectivity**(기종마다 다름). | DICOM 옵션이 켜져 있는지(보통 「옵션/Option」·「About」 화면). 목적지를 「Store」와 「Worklist」로 따로 만드는지. 흑백/컬러·동영상(멀티프레임)을 어떻게 보내는지. |
| 내시경 게이트웨이 PC | 영상은 내시경 옆 **캡처 프로그램**이 보냅니다. 그 프로그램이 **특정 회사 PACS 전용**이면 보낼 곳을 바꿀 수 없을 수도 있습니다. | 캡처 프로그램 이름·버전, DICOM 보내기가 있는지, 라이선스가 필요한지. 워크리스트를 받는지(없으면 환자번호를 손으로). |

## 단계와 판정

device-watch 화면에 뜨는 글자 그대로입니다(한국어).

### ① 장비에서 서버로 닿는가

| 이렇게 나오면 정상 | 이렇게 나오면 → 이것을 봄 |
|---|---|
| 「장비가 연결함 — AE: XRAY01, 주소 192.168.1.50」 (장비의 연결 시험·목록 불러오기·전송 중 무엇을 눌러도) | 아무것도 안 뜨고 「기다리는 중」만 → **선·주소·포트**: 장비의 서버 주소가 서버 PC의 IP인지, 포트 4242인지. 서버 PC에서 `device-watch.bat -Ping <장비 IP>` — 「ping: 응답함」이면 선은 되어 있음. 선은 되는데 연결이 안 뜨면 Windows 방화벽(4242 허용) |
| | `-Ping`에서 「ping: 응답 없음」 → 장비와 서버가 같은 공유기(같은 192.168.x)에 있는지, 케이블, 장비 IP |
| 「장비가 연결 시험(C-ECHO)을 함 → 응답함」 | — |

### ② 목록(워크리스트)을 물어보는가

| 이렇게 나오면 정상 | 이렇게 나오면 → 이것을 봄 |
|---|---|
| 「장비가 목록을 물어봄(워크리스트) — AE: …」 다음 줄 「→ N명 보냄」 | 목록을 불렀는데 아무것도 안 뜸 → 장비의 **워크리스트 목적지**(주소·4242·MEDCONNECT)가 따로 있는지. 워크리스트 기능이 없는 장비일 수 있음(아래) |
| | 「→ 0명 — 장비가 「XRAY01」 앞으로 온 검사만 물음 …」 → 장비의 「내 AE만 / Station AE 거르기」 끄기 |
| | 「→ 0명 — 장비가 CR 검사만 물음. 지금 목록: US 2」 → 장비가 묻는 종류와 EMR 검사 종류가 다름 → 장비의 Modality 거르기를 끄거나, EMR 오더 코드의 Modality를 장비에 맞춤: EMR의 **Paramètres → Codes d'actes**(설정 → 오더 코드)에서 그 검사의 줄을 열고 **Modalité**(장비 (Modality)) 칸에서 **« Autre — saisir la valeur… »**(기타 — 직접 입력…)를 골라 device-watch가 보여 준 값을 **글자 그대로** 넣습니다(예: `AS`; 글자·숫자·밑줄 16자까지) — 목록에 없는 값(「장비가 AS 검사만 물음」)도 이렇게 넣습니다(아래 「EMR 쪽 설정」) |
| | 「→ 0명 — 장비가 날짜 …의 검사를 물음(오늘 …)」 → **장비의 날짜·시계**가 틀림 |
| | 「→ 0명 — 지금 서버에 오늘 목록이 하나도 없음 …」 → EMR에서 오늘 검사를 냈는지, 줄에 Envoyé가 있는지. 「브리지가 EMR에 닿지 못함」이 떠 있으면 EMR이 꺼졌거나 다른 프로그램이 9080을 씀(`check-windows-ports.ps1`) |

### ③ 환자가 보이는가

| 이렇게 나오면 정상 | 이렇게 나오면 → 이것을 봄 |
|---|---|
| 장비 화면에 이름·환자번호(예: 26-00001)·검사 이름이 보임 | 「N명 보냄」인데 장비에 안 보임 → 장비 목록 화면의 날짜·거르기(장비 안에서 한 번 더 거르는 장비가 있음). 이름 글자가 깨지면 사진을 찍어 두기(글자 집합 문제 — 확인 필요) |

### ④ 찍어서 보냈을 때 받는가

| 이렇게 나오면 정상 | 이렇게 나오면 → 이것을 봄 |
|---|---|
| 「장비가 영상을 보냄 — AE: …」 → 「영상 받음 — N장 · 보낸 곳 … · 환자번호 26-00001 · 검사번호 260930-…」 → 「↳ EMR 오더와 연결됨: … 」 「↳ 환자번호 맞음」 | 보냈는데 아무것도 안 뜸 → 장비의 **보내기(Store) 목적지**가 따로 있는지, 주소·4242·MEDCONNECT. 장비에 전송 실패/대기 목록(Queue)이 있으면 그 화면 사진 |
| 「압축 전송(JPEG)」이 붙어도 정상 — 서버가 받습니다 | 「장비가 연결했다가 아무것도 묻거나 보내지 않고 끊음」 → 서버가 **그 전송 방식을 받지 않은 것**일 수 있습니다. 장비의 전송 설정에서 「압축 없음(Uncompressed / Explicit Little Endian)」 같은 선택지가 있으면 바꿔 보기. 안 되면 이 화면을 사진 찍어 총괄에게 |
| | 「↳ 제조사 전용 영상 종류(…) — 서버에 저장했지만 영상 창에서는 안 보일 수 있습니다」 → **받기는 받음**(서버가 모르는 영상 종류도 받도록 해 둠 — 옛 장비가 무엇을 보낼지 몰라서). EMR에는 「Réalisé」·「N image(s) reçue(s)」로 똑같이 기록되지만, 영상 창에 그림이 안 나올 수 있습니다. 장비에 「표준 DICOM으로 보내기」·「Secondary Capture」 같은 선택지가 있으면 바꿔 보고, 그대로면 판독은 장비 화면으로 |
| | 「↳ 그림이 없는 자료 N개(보고서·측정값·원자료 등)」 → 초음파의 측정값·보고서처럼 그림이 없는 자료. 저장은 됨. 그 검사에 **그림 없는 자료만** 왔으면 EMR 영상 창에 「이 검사에는 그림이 없는 자료만 왔습니다(N개) — 장비가 보낸 보고서·측정값 같은 것」 안내가 뜸(프랑스어 화면: «Cette demande n'a reçu que des données sans image …») — 정상. 그림도 함께 왔으면 영상 창에 그림이 나오고, 그림 없는 것은 **눈에 줄 그은 작은 그림**으로 보임 |
| | 「↳ 환자번호가 다름 — 영상 …, 오더 …」 → 장비에서 목록의 다른 환자를 골랐거나 손으로 고침. EMR에 빨간 경고 |
| | 「↳ 영상에 환자번호가 없음」 → 목록에서 고르지 않고 이름만 쳤을 수 있음. EMR에 노란 경고 |
| | 「↳ 장비가 제 검사 UID를 씀 — 검사번호 …로 오더와 연결될 예정」 → 정상(1~2분 뒤 연결). 이 장비는 계속 이렇게 합니다 |
| | 「↳ 연결할 EMR 오더가 없음 — … 손으로 친 환자일 수 있음」 → 영상은 서버에 있지만 EMR 검사와 이어지지 않음. 목록에서 골라 다시 찍기 |

### ⑤ EMR에서 보이는가

| 이렇게 나오면 정상 | 이렇게 나오면 → 이것을 봄 |
|---|---|
| 1~2분 뒤 device-watch 「↳ EMR에 기록됨 — …: 「Réalisé」」, EMR 진료 화면의 그 줄이 **Réalisé**, **🖼**로 영상 창에 영상 | 「Réalisé」인데 영상 창이 비거나 안내 문구 → 설정 → Flux d'ordres 「Tester : visionneuse → serveur d'images」(위키 P-27). 영상 창 안내 문구는 `manual-fr/pacs.md`의 표 |
| 장비 목록에서 그 환자가 빠짐(다음에 목록을 새로 불러올 때) | 계속 남아 있으면 장비가 목록을 새로 불러오지 않은 것 |

## 워크리스트가 안 되는 장비

- 장비에서 **환자번호(차트번호, 예: 26-00012)를 정확히** 치고, 검사 번호 칸이 있으면 EMR 검사 줄의 번호(검사번호, accession)를 칩니다 — device-watch의 「검사번호」와 같은 값.
- 찍어 보내면 device-watch가 「연결할 EMR 오더가 없음」 또는 「검사번호로 연결될 예정」을 말합니다.
  - **검사번호를 맞게 쳤으면** 1~2분 뒤 EMR 오더와 이어지고, 진료 화면의 **🩻 Imagerie (영상/판독)** 목록에 노란 줄 「검사 번호로 연결됨 — 영상 속 환자 정보 확인」.
  - 검사번호가 없으면 EMR 오더와 이어지지 않습니다(영상은 서버에만). 지금은 EMR에서 나중에 이어 붙이는 기능이 없습니다(위키 P-4 3단계).
- EMR의 경고 읽는 법: 빨강 = 영상의 환자번호가 다름, 노랑 = 영상에 환자번호 없음 — `manual-fr/pacs.md` 「Si ce message apparaît」.

## 전송도 안 되는 장비

- 영상 없이 **판독만** 씁니다: 진료 화면의 **🖼 → Compte-rendu** 칸에 소견을 적고 **Enregistrer**. 영상은 장비에서 보거나 인쇄.

## EMR 쪽 설정 (관리자)

- **설정 → Codes d'actes**(오더 코드): 영상 검사마다 **Modality**(CR, DX, US, ES …)와 **워크리스트 켬**. 장비가 「CR만」 묻는데 오더 코드가 DX면 0명 — 장비가 묻는 종류(device-watch의 「조건: Modality=…」)에 오더 코드를 맞추거나, 장비의 Modality 거르기를 끕니다. **흔치 않은 값도 됩니다**: 장비가 「Modality=AS」처럼 처음 보는 값을 물으면 device-watch가 그 값을 그대로 보여 주므로(「→ 0명 — 장비가 AS 검사만 물음. 지금 목록: US 6, CR 5」), 오더 코드의 **Modalité** 칸에서 **« Autre — saisir la valeur… »**(기타 — 직접 입력…)를 골라 **그 글자 그대로**(AS) 넣으면 됩니다(설정 세션 `a703ccb`, 2026-10-01 — 전에는 US·CR·CT·MR·ES·OT만 고를 수 있었음). 종류가 「시술」인 오더 코드(내시경·직장경)여도 됩니다 — Modality가 있으면 영상 검사로 다룹니다. 격리에서 AS로 목록·영상·EMR 화면·판독 보고서까지 확인(2026-10-01).
- **Station AE**: 오더 코드에 칸이 있지만 **지금 EMR은 쓰지 않습니다**(모든 장비에 모든 검사가 보임, 목록에는 `ANY`). 그래서 장비의 「내 AE만」 거르기는 꺼야 합니다. 방이 여럿이라 장비마다 나눠야 하면 총괄에게(설계 변경).
- **설정 → Flux d'ordres**: Host / IP `host.docker.internal`, DICOM Port 4242, 「Tester PACS (DICOM)」와 「Tester : visionneuse → serveur d'images」 둘 다 ✓.

## device-watch가 보는 것 (궁금할 때)

- 영상 받음·환자번호·검사번호·압축·영상 종류는 영상 서버의 변경 기록에서 읽습니다 — 언제나 보입니다.
- 「영상 서버가 … 알림」 줄은 **장비 연결 중에** 생긴 경고만입니다(쉬운 말 + 아래 괄호에 원문). 관리 화면·EMR 영상 창 쪽 경고는 보이지 않게 거릅니다.
- **서버가 모르는 영상 종류도 받습니다**(2026-09-30 총괄 결정). 디스크를 조금 더 씁니다. 되돌리려면 PACS 폴더의 `docker-compose.yml`에서 `ORTHANC__UNKNOWN_SOP_CLASS_ACCEPTED`를 `"false"`로 → `docker compose up -d`(영상 서버가 다시 시작됨) — 총괄에게 부탁하세요.
- 장비 연결·연결 시험·목록 조회는 영상 서버가 **자세히 기록할 때만** 남습니다 → 그래서 `device-watch.bat`이 「자세히 보기」로 켭니다(끝낼 때 되돌림).
- 목록이 0명인 이유는 서버에 있는 오늘 목록(파일)과 장비가 물은 조건을 맞춰 보고 말합니다. EMR 오더와의 연결은 EMR 데이터베이스를 **읽기만** 해서 맞춰 봅니다.
- 설정을 몰래 바꾸지 않습니다. 바꾸는 것은 「자세히 보기」 하나이고, 화면에 그렇게 말합니다.
