## 의사 선생님께 드릴 질문지

「의사 확인 대기」인 항목을 의사 선생님께 그대로 보여 드릴 수 있게 적은 것입니다. 답을 받으시면 결정 세션에 알려 주세요.

### 1. 수술기록지 체크 칸 (2026-09-29)

수술기록지에서 아래 세 칸은 지금 **여러 개를 체크할 수 있습니다.** 한 환자에서 두 가지 이상에 해당하는 경우가 실제로 있습니까? 없다면 「하나만 체크」로 바꿔 실수를 막으려 합니다.

| 칸 | 선택지 | 여쭙는 것 | 답 (여러 개 / 하나만) |
|---|---|---|---|
| 충수 위치 (충수절제술) | Retrocecal · Preileal · Postileal · Subcecal · Pelvic | 한 환자에서 위치를 두 개 이상 적을 일이 있습니까? | |
| 삼출액 성상 (충수절제술) | Pus · Turbid · Serous | 두 가지를 함께 적을 일이 있습니까? (예: 부위마다 다를 때) | |
| 병변 위치 (연부조직) | Skin · Soft tissue (subcutaneous) | 피부와 피하조직에 걸친 병변은 둘 다 체크합니까? | |
| 병변 종류 (연부조직) | Epidermal cyst · Granuloma · Lipoma · Hemangioma · Fibroma · Giant cell tumor · Myositis ossificans · Sarcoma · Other | 한 번 수술에서 종류가 다른 병변을 둘 이상 떼는 경우, 기록지 한 장에 함께 적습니까? | |

### 2. 약속처방에 넣을 약 용량 (2026-09-29, 다시 고침)

처방 화면의 칸은 한국식 **하루 총량(일총투여) / 횟수 / 일수**이고 총량은 **하루 총량 × 일수**입니다. 약품 설정에서는 기본 용량을 정하지 않습니다 — 의사가 약을 하나씩 넣을 때는 직접 적고, 자주 쓰는 처방은 **약속처방**에 용량까지 넣어 둡니다. 약속처방을 실제 약으로 다시 이을 때 아래를 정해 주세요.

| # | 여쭙는 것 | 답 |
|---|---|---|
| 1 | 말라리아 약속처방(Malaria Workup)에 넣을 약과 용량 — **M-Artefix 80mg/480mg** 또는 **Combimal**을 「하루 총량 / 횟수 / 일수」로 어떻게 적습니까? (예: 1회 1정 × 하루 2번 × 3일이면 2 / 2 / 3) | |
| 2 | 설사·장염 약속처방(Diarrhea/GE)에 넣을 약과 용량 — ORS는 하루 몇 포를 몇 번에 나눠 며칠? | |
| 3 | 그 밖에 만들어 두고 싶은 약속처방이 있습니까? | |

예시 약으로 계산한 참고 표: `wiki/reference/dose-check-for-doctors.md`

### 3. 검사 참고치 (2026-09-29) — 표는 `wiki/reference/lab-reference-ranges-kr.md`

현장 검사 장비는 모두 한국에서 가져간 장비입니다. 한국 자료를 찾아 참고치 제안표를 만들었습니다(한국산 장비 전용 참고치는 찾지 못했습니다). 표를 보시고 아래를 정해 주시면, 그 값만 EMR에 넣습니다.

| # | 여쭙는 것 | 답 |
|---|---|---|
| 2 | 중성지방은? 150 / 200 | |
| 3 | LDL은? 130 / 160 | |
| 4 | eGFR은 어느 선 아래부터? 60 / 90 | |
| 5 | HDL이 60을 넘으면 이상으로 표시하지 않아도 됩니까? | |
| 6 | 요단백 등에서 Trace(미량)를 이상으로 봅니까? | |
| 7 | 남/여, 소아를 나눠 봐야 하는 항목은 어디까지입니까? (Hb·Hct·RBC·크레아티닌·요산·ALP·WBC 등, 소아 나이 구분) | |
| 8 | 제안표의 값 가운데 고칠 것이 있습니까? | |

### 4. 수술기록지 소견 문장 (2026-09-29) — 자세한 것은 `wiki/modules/consultation.md` 7.4

수술기록지의 소견 칸에는 기본 문장이 미리 들어 있고, 고쳐 써야 하는 자리는 괄호로 표시되어 있습니다(예: `[anesthesia]`, `[lithotomy/jackknife]`). 괄호를 안 고치고 발급하려 하면 경고가 뜹니다.

| # | 여쭙는 것 | 답 |
|---|---|---|
| 1 | 기본 문장과 괄호 자리가 실제 기록하시는 방식에 맞습니까? 빼거나 더할 괄호 자리가 있습니까? | |
