# Guide du personnel (français) — 현지 직원용 사용 설명서

> 현지 직원(접수·간호사·의사)이 **인쇄해서 옆에 두고 보는** 프랑스어 설명서입니다.
> 각 모듈 세션이 자기 위키 2절(한국어 사용법)을 바탕으로 자기 파일을 씁니다. 총괄이 모아 한 권으로 묶습니다.
> 시작: 2026-09-29.

## 쓰는 규칙

1. **프랑스어로만.** 짧은 문장, 명령형(« Cliquez sur … », « Saisissez … »). 전문 용어보다 화면에 보이는 말.
2. **화면의 글자는 `frontend/src/i18n/fr.js`에 있는 그대로**, 굵게: **Enregistrer**, **Terminé**. 설명서의 말과 화면의 말이 다르면 직원이 단추를 못 찾습니다 — 쓰기 전에 격리 스택을 프랑스어로 띄워 실제 화면과 대조합니다.
3. 구성(모든 파일이 같은 순서):
   - `# <모듈 이름>` 한 줄 소개 — 이 화면에서 무엇을 하는지, 누가 쓰는지
   - `## En bref` — 가장 흔한 일을 5~8단계로(번호 목록)
   - `## Pas à pas` — 일마다 소제목, 번호 단계. 한 단계에 한 동작
   - `## Si ce message apparaît` — 표: 화면에 뜨는 말(그대로) · 무슨 뜻 · 무엇을 하면 되는지
   - `## À ne pas faire` — 하면 안 되는 것 3~6줄
   - `## Qui appeler` — 스스로 못 고칠 때(관리자에게 알릴 것)
4. 환자 이름·번호는 **가짜만**(예: RAKOTO Jean, 26-00001). 실제 환자 정보, 비밀번호, 토큰은 절대 쓰지 않습니다.
5. 그림을 넣으려면 격리 스택(가짜 환자)에서 1366×768로 떠서 `wiki/manual-fr/img/<모듈>-<번호>.png`(한 장 300KB 이하, 모듈마다 6장 이내). 그림 없이도 읽히게 글을 먼저 씁니다.
6. 길이: 모듈마다 인쇄 A4 2~4쪽. 자주 하는 일부터. 드문 일은 짧게.
7. 아직 EMR에 없는 기능은 쓰지 않습니다. 다른 세션이 작업 중이라 곧 바뀔 화면은 `<!-- à revoir : … -->` 주석으로 표시.
8. 프랑스어가 확실하지 않은 의학·행정 용어는 `<!-- terme à vérifier sur place : … -->` 주석을 달아 둡니다(현지 확인 목록으로 모음).
