# 현장에 가져가기 전 확인 목록

> 실장님 PC의 EMR은 시험용입니다. **마다가스카르에 가져가기 전에** 아래를 모두 확인합니다.
> 총괄이 관리합니다. 끝난 것은 ✅와 날짜, 확인한 사람을 적습니다.

## 0. 자료를 어떻게 가져가나 — **(b) 현지의 다른 PC에 새로 설치** (실장님 결정 2026-09-29)

> 이 PC에서 넣은 약 목록·가격·병원 정보·계정은 **백업 파일로 옮기고**, 시험 데이터는 복원한 뒤에 정리합니다.
> 그래서 출발 전에 「빈 PC에 설치 → 백업 복원 → 확인」을 처음부터 끝까지 한 번 연습합니다(4절).

새 PC에 설치 묶음(`OFFLINE-INSTALL.md`)으로 설치하면 **빈 DB(초기 설정 화면)** 로 시작합니다. 실장님 PC에서 넣은 약 가격·기본 용량, 오더 코드, 병원 정보, 상용구, 직원 계정은 따라가지 않습니다.

| 방법 | 할 일 |
|---|---|
| (a) **이 PC를 그대로 가져감** | 아래 목록대로 이 PC에서 정리 |
| (b) **새 PC에 설치** | 이 PC에서 설정 → 백업 → 「지금 백업」 → 내려받기 → 새 PC에서 `DEPLOYMENT.md` 5b로 복원. 시험 데이터·시험 계정·비밀번호도 같이 오므로 **복원한 뒤에** 3절 정리. 복원 연습은 4절의 오프라인 설치 시험 때 같이. **관리자 비밀번호를 알고 가야 함**(계정이 그대로 옮겨 가고, 새 PC에서는 초기 설정 화면이 안 나옴). 절차와 실제로 해 본 기록(손으로 약 5분): [modules/settings.md](modules/settings.md) 2.13절 |

✅ 2026-09-29 실장님 결정: **(b)**. 아래 목록에서 「이 PC에서 정리」라고 적힌 것은 복원한 뒤 현지 PC에서 합니다.

| 상태 | (b)라서 출발 전에 할 것 |
|---|---|
| ☐ | 설치 묶음 만들기(`OFFLINE-INSTALL.md`) — EMR과 PACS 둘 다, USB 두 개에 |
| ☐ | 마지막 백업 파일 + `.env` 사본을 USB에 (같은 USB 두 개에) |
| ☐ | **연습**: 인터넷을 끊은 다른 PC(또는 빈 Docker)에 설치 묶음으로 설치 → 백업 복원 → 로그인·환자·약·가격·계정·변경 기록이 그대로인지 확인 |
| ☐ | 관리자 비밀번호를 알고 감 (복원하면 초기 설정 화면이 나오지 않음) |

## 1. 약 — 의사 선생님 답이 필요한 것 (가장 중요)

처방 입력은 한국식입니다(2026-09-29 결정): 용량 칸 = **하루 총량**, 총량 = 하루 총량 × 일수.
아래 약은 기본값을 그대로 쓰면 의도와 다른 양이 나갈 수 있습니다. 표와 질문은 [reference/dose-check-for-doctors.md](reference/dose-check-for-doctors.md).

| 상태 | 확인할 것 |
|---|---|
| ☐ | **말라리아약 ACT01** 기본값 4/2/3 → 새 식으로 **12정**. 「1회 4정 × 하루 2번 × 3일 = 24정」이 맞다면 **8/2/3**으로 고쳐야 함. 안 고치면 절반만 나감 |
| ☐ | **ORS** 1/3/3 → 3포. 「1회 1포 × 하루 3번」이면 3/3/3 |
| ☐ | **Prednisolone 5mg** 3/1/5 — 1회 3정이 맞는지 |
| ☐ | **약속처방(오더 세트)** 은 약 기본값의 복사본 — 기본값을 고치면 세트의 같은 줄도 고칠 것 (Malaria Workup, Diarrhea/GE) |
| ☐ | **시럽·흡입기·안약 등 병·개 단위 약** — 총량을 병·개 수로 넣는 방법이 정해졌는지 |
| ☐ | 실제 약 105줄을 가져온 뒤: **가격**과 **기본 용량**이 채워졌는지 (가져온 직후에는 모두 비어 있음 → 0원 청구) |

## 3. 계정·보안

| 상태 | 확인할 것 |
|---|---|
| ☐ | 시험 계정(zz…) 정리 — **지우는 기능은 없고 「삭제」는 비활성**입니다. 목록에 남고 그 아이디는 다시 못 씁니다(비활성 계정을 관리자가 되살리는 기능은 설정 세션이 만드는 중 — 결정 2026-09-29). 실제 직원이 쓸 아이디로 시험 계정을 만들지 말 것 |
| ☐ | **이미 있는 의사 계정에 약국 권한 주기** — 의사 기본 권한이 진료+약국으로 바뀌었지만(결정 2026-09-29) 새로 만드는 계정에만 적용됨. 기존 의사 계정(Dr. Lee)은 설정 → 직원 → 수정 → 약국 체크 |
| ☐ | 실제 직원 계정 생성 — 창구는 Accueil(접수, 기본 권한 접수+수납), 간호사는 Infirmier(ère)(기본 접수+약국+임상병리), 수납만 하는 직원은 접수 체크 해제 |
| ☐ | 새 직원의 **초기 비밀번호는 1234**(결정 2026-09-29) — 직원이 각자 자기 비밀번호로 바꾸게 안내(자기 비밀번호 바꾸기 화면은 설정 세션이 만드는 중). 모두 1234로 남으면 남의 계정으로 들어갈 수 있어 「누가 입력했는지」와 변경 기록의 뜻이 없어짐 |
| ☐ | **관리자 계정 보호**: 설치 때 만든 관리자 아이디가 `admin`이어야 잠금 방지가 적용됨. 새로 설치하면 초기 설정 화면에서 아이디를 admin으로, 아니면 관리자+설정 권한 계정을 둘 둘 것 |
| ☐ | 관리자 비밀번호를 현장용으로 변경 — 설정 → 직원 → admin 줄 수정 → 비밀번호. 비밀번호를 바꿔도 이미 로그인한 화면은 그대로 열려 있으니 바꾼 뒤 각 PC에서 로그오프 (계정 비활성·권한 변경은 2026-09-29부터 바로 적용됨) |
| ☐ | `.env` 파일 사본을 USB에 — 잃으면 DB를 열 수 없음(`DEPLOYMENT.md` 4절) |
| ☐ | PACS 브리지 토큰 — **현지 PC에 새로 설치할 때 새로 만들어짐.** 이 PC의 토큰 재발급(재부팅 뒤)은 이 PC의 시험용에만 해당 |
| ☐ | **관리자 계정만큼은 1234가 아닌 비밀번호로** — 초기 비밀번호는 1234이고 첫 로그인 때 바꾸라고 강제하지 않음(결정 2026-09-29). 관리자 계정은 설정·변경 기록·백업을 모두 만질 수 있음 |
| ☐ | 시험 데이터(환자 2명, 영수 2건, 처방 6건)를 지우고 갈지 |

## 4. 설치·장비

| 상태 | 확인할 것 |
|---|---|
| ☐ | 서버 PC의 Windows 동적 포트 범위가 기본값(49152~)인지 — `DEPLOYMENT.md` |
| ☐ | 백업 위치를 다른 드라이브로 — `.env`의 `BACKUP_PATH` 후 재시작. 확인: 설정 → 백업 탭의 저장 위치가 그 경로이고 **초록 띠** |
| ☐ | 「지금 백업」 직후 `verify-backup.ps1 -Strict` → VERIFIED (낮에 그냥 돌리면 [info]가 나오는 것이 정상) |
| ☐ | **병원 밖 USB 사본**(백업 탭 내려받기)을 누가, 얼마나 자주 할지 정했는지 |
| ☐ | `.env`의 `TZ=Indian/Antananarivo` — 백업 시각과 「오늘」 기준 |
| ☐ | **EMR을 여는 PC마다 Windows 시간대가 마다가스카르(UTC+3)인지** — 한국 시간으로 맞춰진 PC에서는 저녁 6시 이후의 검사 결과·판독 날짜가 다음 날로 보임 |
| ☐ | **방사선사 안내: 촬영 전에 장비의 환자 목록(워크리스트)을 새로 불러오기** — 의사가 지우거나 취소한 오더가 장비 화면에는 다시 불러올 때까지 남을 수 있음. 그대로 찍으면 영상이 오더에 붙지 않거나 취소된 오더에 붙음 (결정 2026-09-29, `modules/pacs.md`) |
| ☐ | **서버 상태 창**(`server-status.bat`)을 서버 PC 시작 프로그램에 두고 7줄 모두 초록인지 — 특히 영상(Imagerie)이 「포트 막힘」이 아닌지 |
| ☐ | `DEPLOYMENT.md` 9절 「Before you go live」(방화벽, 포트 포워딩 금지, Wi-Fi면 HTTPS, Docker 자동 시작)도 같이 확인 |
| ☐ | 오프라인 설치 묶음으로 새 PC에 설치해 보았는지 |
| ☐ | 프린터 용지(A4), 영상 장비 연결(PACS 절차서 D-1~D-6) |
