# 현장에 가져가기 전 확인 목록

> 실장님 PC의 EMR은 시험용입니다. **마다가스카르에 가져가기 전에** 아래를 모두 확인합니다.
> 총괄이 관리합니다. 끝난 것은 ✅와 날짜, 확인한 사람을 적습니다.

## 0. 자료를 어떻게 가져가나 — **(b) 현지의 다른 PC에 새로 설치** (실장님 결정 2026-09-29)

> 이 PC에서 넣은 약 목록·가격·병원 정보·계정은 **백업 파일로 옮기고**, 시험 데이터는 복원한 뒤에 정리합니다.
> 그래서 출발 전에 「빈 PC에 설치 → 백업 복원 → 확인」을 처음부터 끝까지 한 번 연습합니다(4절).

새 PC에 설치 묶음(`OFFLINE-INSTALL.md`)으로 설치하면 **빈 DB(초기 설정 화면)** 로 시작합니다. 실장님 PC에서 넣은 약 가격·기본 용량, 오더 코드, 병원 정보, 상용구, 직원 계정은 따라가지 않습니다.

| 방법 | 할 일 |
|---|---|
| (a) **이 PC를 그대로 가져감** | 아래 목록대로 이 PC에서 정리 |
| (b) **새 PC에 설치** | 이 PC에서 설정 → 백업 → 「지금 백업」 → 내려받기 → 새 PC에서 `DEPLOYMENT.md` 5b로 복원. 시험 데이터·시험 계정·비밀번호도 같이 오므로 **복원한 뒤에** 3절 정리. 복원 연습은 4절의 오프라인 설치 시험 때 같이. **관리자 비밀번호를 알고 가야 함**(계정이 그대로 옮겨 가고, 새 PC에서는 초기 설정 화면이 안 나옴). 절차와 실제로 해 본 기록(손으로 약 5분): [modules/settings.md](modules/settings.md) 2.13절 |

✅ 2026-09-29 실장님 결정: **(b)**. 아래 목록에서 「이 PC에서 정리」라고 적힌 것은 복원한 뒤 현지 PC에서 합니다.

| 상태 | (b)라서 출발 전에 할 것 |
|---|---|
| ☐ | 설치 묶음 만들기(`OFFLINE-INSTALL.md`) — EMR과 PACS 둘 다, USB 두 개에 |
| ☐ | **이 PC를 설치 묶음과 같은 버전으로 맞춘 뒤** 마지막 백업을 만듦(설정 → 백업 → 지금 백업) → `verify-backup.ps1 -Strict`로 확인 → 그 파일 + `.env` 사본을 USB 두 개에. 옛 버전에서 만든 백업은 새 설치 위에 보통 명령으로 복원되지 않음(`DEPLOYMENT.md` 5b 「백업이 앱보다 옛 버전일 때」) |

| ☐ | 관리자 비밀번호를 알고 감 (복원하면 초기 설정 화면이 나오지 않음) |

| ☐ | 현지 PC에서도 **포트 범위 확인**: `netsh int ipv4 show dynamicport tcp` → 시작 49152 (Docker 설치·재부팅 뒤). 아니면 `DEPLOYMENT.md`의 두 줄 실행 후 재부팅 |
| ☐ | 서버 PC의 **IP 고정**, 다른 PC에서 **9080**과 **4242**(영상 장비) 연결 확인(`Test-NetConnection`), Windows 방화벽. 9090은 서버 PC 안에서만 열림 — 직원 PC에는 필요 없음(영상은 EMR 영상 창으로) |
| ☐ | 복원 **뒤에** PACS 폴더에서 `.\pair-with-emr.ps1` 한 번(EMR과 PACS의 브리지 토큰을 다시 맞춤, 값은 화면에 나오지 않음), 설정 → 오더 연동의 뷰어 주소·피드 주소를 서버 LAN IP로 — 두 주소는 백업과 함께 옛 PC의 값으로 넘어옴 (`modules/pacs.md` 6.1) |
| ☐ | 설치 묶음은 PACS 저장소 `main`이 최신이고 `git status`가 빈 상태에서 만들 것, 묶음 안에 `.env` 계열 파일이 없는지 확인 |

## 1. 약 — 의사 선생님 답이 필요한 것 (가장 중요)

처방 입력은 한국식입니다(2026-09-29 결정): 용량 칸 = **하루 총량**, 총량 = 하루 총량 × 일수.
아래 약은 기본값을 그대로 쓰면 의도와 다른 양이 나갈 수 있습니다. 표와 질문은 [reference/dose-check-for-doctors.md](reference/dose-check-for-doctors.md).

| 상태 | 확인할 것 |
|---|---|
| ☐ | **말라리아약 ACT01** 기본값 4/2/3 → 새 식으로 **12정**. 「1회 4정 × 하루 2번 × 3일 = 24정」이 맞다면 **8/2/3**으로 고쳐야 함. 안 고치면 절반만 나감 |
| ☐ | **ORS** 1/3/3 → 3포. 「1회 1포 × 하루 3번」이면 3/3/3 |
| ☐ | **Prednisolone 5mg** 3/1/5 — 1회 3정이 맞는지 |
| ☐ | **약속처방(오더 세트)** 은 약 기본값의 복사본 — 기본값을 고치면 세트의 같은 줄도 고칠 것 (Malaria Workup, Diarrhea/GE) |
| ☐ | **시럽·흡입기·안약 등 병·개 단위 약** — 총량을 병·개 수로 넣는 방법이 정해졌는지 |
| ☐ | 실제 약 105줄을 가져온 뒤: **가격**과 **기본 용량**이 채워졌는지 (가져온 직후에는 모두 비어 있음 → 0원 청구) |


### 현지에서 할 일 (실장님 결정 2026-09-29 — 약 항목만 넣고 나머지는 현지에서)

| 상태 | 할 일 |

| ☐ | 포장 단위 「확인」 4줄 — Hemorex, Madecassol 3줄이 알약인지 연고인지 보고 설정 → 약품에서 표시 |

| ☐ | 약속처방에 넣을 약과 용량 — 말라리아약 포함 (의사 질문지 ②). 약속처방을 실제 약으로 다시 이을 때 같이 |
