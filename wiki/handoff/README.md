# 인계 노트 쓰는 법

각 세션은 작업 단위가 끝날 때마다 `wiki/handoff/<코드>.md`의 **맨 위에** 새 항목을 추가합니다.
총괄 세션은 이 노트를 보고 확인하고 `develop`에 합칩니다. 그래서 **빠짐없이, 사실대로** 씁니다.

## 형식

```markdown
## 2026-10-02 — 대기 목록에 호출 버튼 추가

- **상태**: 확인 요청 / 작업 중 / 보류
- **커밋**: session/reception `a1b2c3d` .. `d4e5f6a`
- **한 일**: 무엇을 왜 바꿨는지 두세 줄
- **바꾼 파일**: 자기 파일 목록
- **공용 파일 변경**: 없음 / 파일 · 무엇을 · 왜  ← 반드시 적기
- **DB 마이그레이션**: 없음 / `backend/sql/101_reception_call_button.sql` · 무엇을
- **번역 키**: 없음 / `rc_callPatient` 외 N개 (ko · en · fr 모두 넣음)
- **확인한 방법**: 빌드 통과, 격리 스택 9181 에서 무엇을 눌러 봤는지, 한국어·프랑스어
- **확인 못 한 것**: 솔직하게
- **위키**: `modules/reception.md` 몇 절을 고쳤는지
- **총괄 확인 요청**: 합치기 전에 총괄이 꼭 봐야 할 것
- **다른 세션에 부탁**: 없음 / 어느 세션 · 무엇을
- **남은 일 · 알려진 문제**:
```

## 상태

- **확인 요청** — 합쳐도 된다고 판단한 것. 총괄이 확인합니다.
- **작업 중** — 중간 기록. 합치지 않습니다.
- **보류** — 실장님 결정을 기다리는 것. 무엇을 기다리는지 적습니다.
